# AV Gigz

Music marketplace connecting producers and artists in Uganda.

Connected to a live Supabase database (see `src/supabaseClient.js`).
This version has real sign up, log in, profiles, and gig posting.
Bookings, chat, and wallet are wired in the database already
(see the SQL schema) and connect to the UI next.

## Local development

npm install
npm run dev

## Deploy
Push this repo to GitHub, then import it in Vercel — it auto-detects Vite and deploys.
